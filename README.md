# Hangman
Spânzurătoarea pentru Politehniști
Am realizat implementarea jpocului Spânzurătoarea (Hangman), în limbajul Python, folosind Tkinter, destinat studenților și pasionaților de electronică și inginerie. Jocul folosește termeni tehnici și include un sistem de scor, indicii și bonusuri.

Descriere
Jucătorul trebuie să ghicească un cuvânt tehnic, literă cu literă, înainte de a epuiza numărul maxim de greșeli. Cuvintele sunt însoțite de indicii explicative, iar dificultatea poate fi aleasă la începutul jocului.

Funcționalități:
-Interfață grafică realizată cu Tkinter
-Două niveluri de dificultate:
      *Ușor – termeni de bază
      *Dificil – termeni avansați

Sistem de scor:
-Un punct pentru fiecare literă ghicită
-Bonus la final în funcție de dificultate
-Indiciu (disponibil după ghicirea a minim 4 litere)
-Literă bonus (costă 3 puncte)
-Desenarea progresivă a spânzurătorii
